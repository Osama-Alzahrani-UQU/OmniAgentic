# AI Image Prompt Crafting Guide

A comprehensive guide for crafting high-fidelity prompts across software interfaces, document figures, and game assets using AI image generators.

---

## 1. The 5-Part Formula for High-Quality Prompts

```
[Subject & Focal Point] + [Art Style & Medium] + [Lighting & Atmosphere] + [Color Palette & Details] + [Composition & Camera Angle]
```

### Negative Framing (What to Avoid in Prompt):
- Avoid generic phrases like "high quality", "photorealistic", "8k", "hyper-detailed" which degrade output variance.
- Instead, specify concrete camera/lens settings (`shot on 35mm lens, f/1.8, natural soft studio lighting`) or medium details (`clean vector illustration, flat colors, SVG aesthetic`).

## 2. Domain-Specific Prompt Templates

- **Hero Illustration**:
  > *"Isometric 3D illustration of a modern cloud computing data dashboard, glowing server racks, subtle holographic telemetry charts, deep navy and cyan color scheme, minimalist design, clean white background, soft ambient occlusion shadows, professional SaaS aesthetic."*
- **App Icon**:
  > *"Minimalist vector app icon of a golden security shield with a keyhole emblem, rounded corners, subtle glassmorphism gradient, deep slate background, centered composition, iOS app store style, clean lines."*

### B. Publication Documents (PDF & Word)
- **Technical Architecture Diagram**:
  > *"Clean technical architecture infographic depicting microservices interacting via an API gateway, modern tech enterprise aesthetic, high-contrast monochrome with blue accents, crisp vector lines, white background, presentation grade."*
- **Executive Report Figure**:
  > *"Editorial-style flat design illustration of renewable energy infrastructure with solar panels and wind turbines, subtle texture overlay, muted earth tones, minimalist composition, suitable for an annual ESG corporate report."*
